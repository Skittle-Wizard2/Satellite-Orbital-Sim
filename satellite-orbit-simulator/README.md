# Satellite Orbit Simulator

A Python project for modeling and visualizing satellite orbital motion, orbital mechanics, and mission scenarios.

## Planned Features
- Orbital parameter simulation for satellites and spacecraft
- Keplerian and numerical orbit propagation
- Visualization of orbital paths in 2D and 3D
- Analysis of altitude, velocity, and orbital period
- Scenario-based simulations for Earth-centered orbits
- Interactive dashboard or streamlit-based interface for exploring results
